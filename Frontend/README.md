# Inside The Book

**A QR code generator for bookstore owners that lets customers read a book's description without ever touching it.**

## Overview

Customers often pick up, flip through, and put back the same book many times before buying. Each handling adds wear: fingerprints, bent corners, creased spines and marked pages. BookScan QR lets store owners generate a QR code for each title. Customers scan it with their phone and instantly see the book's description, so the physical copy stays clean and in original condition.

## Why use it

- **Keeps books clean.** Fewer hands on the book means fewer fingerprints, stains and smudges.
- **Preserves the original print.** Covers and dust jackets stay free of scuffs and fading from repeated handling.
- **Protects the paper.** Pages and spines are not bent, creased or worn down by browsing.
- **Helps customers understand the book.** Scanning shows a clear description, so shoppers know what the book is about before deciding to buy.

## How it works

1. The store owner enters a book's details (title, author, description).
2. The app generates a unique QR code for that book.
3. The owner prints the code and places it on the shelf, display or a tag next to the book.
4. A customer scans the code with their phone camera.
5. The book's description page opens right away, with no app install needed.

## Features

- Generate a QR code for each book in a few clicks
- Add title, author, description and cover image
- Download codes as PNG or SVG for printing
- Mobile-friendly description pages
- Edit a description at any time without reprinting the code

## Who it's for

Independent bookstores, second-hand and antique book dealers, rare-book sellers, libraries, and anyone who wants to keep their stock in the best possible condition while helping customers choose.
